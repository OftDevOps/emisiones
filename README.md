# Sistema de Rutas de Pago Oftalmi

Repositorio oficial del proyecto **emisiones**, orientado a gestionar rutas de pago, solicitudes, documentos soporte, aprobaciones, rechazos, devoluciones, cuentas por pagar, ejecución de pagos, auditoría, notificaciones y control documental para Laboratorios Oftalmi.

## Alcance inicial

El MVP se implementará inicialmente para Laboratorios Oftalmi, dejando la arquitectura preparada para futuras empresas del grupo.

## Stack tecnológico

- Backend: Python + Django + Django REST Framework
- Frontend MVP: Django Templates + HTMX
- Frontend futuro: React + react-i18next
- Base de datos: PostgreSQL
- Infraestructura: Docker + Docker Compose
- Servidor: Ubuntu Server o Debian
- Web server: Nginx
- App server: Gunicorn
- Tareas asíncronas: Celery + Redis
- Notificaciones: App interna, correo corporativo Microsoft 365 y Microsoft Teams
- Autenticación: correo electrónico como username
- Auditoría: modelo propio
- Idiomas: español por defecto, inglés secundario

## Principios del proyecto

- Ciberseguridad desde el diseño.
- Ingeniería de software aplicada.
- Ingeniería DevOps aplicada.
- Auditoría completa.
- Rutas versionadas.
- Snapshots históricos por solicitud.
- Documentos soporte digitales.
- Notificaciones formales y operativas.
- Multiempresa preparada desde el diseño.

## Estado del proyecto

Fase inicial de estructuración.
