# Alcance - Sistema de Rutas de Pago Oftalmi

## Definición

El Sistema de Rutas de Pago Oftalmi gestionará solicitudes de pago, facturas, adelantos y otros compromisos mediante rutas aprobatorias dinámicas, configurables, notificadas, auditables y versionadas.

## Alcance inicial

El MVP será para Laboratorios Oftalmi, dejando la arquitectura preparada para futuras empresas del grupo.

## Fase 1 - Núcleo MVP

- Login por correo.
- Usuarios y roles.
- Unidades organizativas.
- Solicitudes de pago.
- Documentos soporte digitales.
- Adelantos justificados.
- Ruta básica de aprobación.
- Aprobación, devolución y rechazo.
- Bandejas de trabajo.
- Cuentas por Pagar.
- Ejecución de pago.
- Auditoría básica.
- Branding Oftalmi.

## Fase 2 - Operación controlada

- Notificaciones por correo corporativo.
- Alertas por Microsoft Teams.
- Tareas de flujo.
- Búsqueda avanzada.
- Pagos programados básicos.
- Historial por nodo.

## Fase 3 - Robustez

- Versionamiento completo de rutas.
- Snapshots históricos.
- Reglas avanzadas.
- Documentos versionados.
- Pagos recurrentes.
- Reportes operativos.

## Fase 4 - Escalamiento

- Multiempresa.
- Branding configurable.
- Microsoft Entra ID.
- Integración ERP.
- Integración bancaria futura.
- Dashboards gerenciales.
