# Ciberseguridad - Sistema de Rutas de Pago Oftalmi

## Principio

La ciberseguridad forma parte del diseño del sistema, no es un agregado posterior.

## Controles iniciales

- Autenticación por correo.
- Preparado para Microsoft Entra ID.
- Roles y permisos.
- Control por unidad organizativa.
- Auditoría de acciones críticas.
- Protección de documentos soporte.
- Acceso controlado por nodo y rol.
- No envío de documentos por correo o Teams.
- Validaciones en backend.
- Registro de cambios de estado.
- Registro de aprobación, rechazo y devolución.

## Reglas

- Todo pago debe tener trazabilidad.
- Todo documento debe tener control de acceso.
- Todo rechazo debe exigir motivo.
- Todo cambio crítico debe auditarse.
- La app es la fuente oficial de verdad.
