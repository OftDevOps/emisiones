# Branding - Sistema de Rutas de Pago Oftalmi

## Identidad visual

El MVP utilizará la identidad visual de Laboratorios Oftalmi.

## Colores corporativos

| Color | Hex |
|---|---|
| Azul | #1226AA |
| Morado | #8A1A9B |
| Amarillo | #FFE800 |
| Celeste | #6FCFEB |

## Elemento gráfico

El área de diseño gráfico utiliza como recurso visual el contorno de una cápsula.

## Logo

El logo oficial deberá ser suministrado por el área responsable y almacenado en:

```text
backend/static/img/logo-oftalmi.svg
backend/static/img/logo-oftalmi.png
```

## Regla

El branding inicial será Oftalmi, pero la arquitectura debe permitir branding configurable para futuras empresas del grupo.
